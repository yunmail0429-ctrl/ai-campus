# 项目落地方案

依据：PRD.md、DEVELOPMENT.md，以及当前 index.html、workspace.js、chat.js、skills.js、settings.js。

## 当前证据

- 登录仅检查 teacher 字符串，不验证密码。
- 对话与 Skill 使用内存数据；刷新丢失，未调用模型。
- 附件只保存文件名，未上传；创作中心未创建任务。
- 设置保存于浏览器 localStorage，积分为展示值。
- 当前目录没有后端工程，也不是 Git 仓库。

## 推荐架构

根据用户确认，保留现有页面视觉和交互，前端按开发文档使用 React / Next.js + TypeScript + Tailwind CSS + TanStack Query。页面使用 App Router 和 React 组件，不加载旧页面脚本，也不通过 iframe 嵌入原型。原 HTML 和 JS 仅作为迁移对照。增加统一 API 客户端；后端采用 FastAPI 模块化单体，PostgreSQL + pgvector 持久化，Redis + Celery 处理任务，S3 兼容私有存储保存附件和产物。通过 Docker Compose 提供本地环境。模型均通过适配器调用，凭据使用环境变量引用。

前端迁移现在执行，沿用校徽、蓝白配色、校园登录背景、手动折叠侧栏、工作台卡片和对话三栏布局。服务端权限和数据持久化不依赖前端路由保护。

## 实现顺序与完整范围

1. 基础：数据库迁移、租户上下文、账号密码登录、会话撤销、Argon2id、教师与管理员 RBAC、统一错误与 requestId、限流、配置、健康检查。
2. 教师业务：个人资料与偏好、会话列表/重命名/删除、持久化消息与草稿、SSE 对话、工作台最近工作、资源版本与导出。
3. Skill：个人草稿、编辑、试用、提交审核、管理员退回/发布/下架/回滚，保存不可变版本；公共发布校验五个测试样例、预期输出、风险边界、年级、负责人和回滚信息。
4. 知识库：个人及学校知识库、权限范围、真实上传、解析和 OCR 适配、切片、Embedding、检索与引用、资料下线；处理状态持久化。
5. 生成与额度：统一模型路由、超时与降级、脱敏和安全检查、使用计量；额度原子预占/结算/释放与幂等，避免重试重复扣费。
6. 创作中心：图片、PPT、音频、视频、数字人、3D 的提交、进度、取消、重试、下载；Outbox 发布、幂等 Worker、指数退避与死信。
7. 管理后台：账号启停、知识库、Skill 审核、模型配置、额度分配、使用统计和脱敏导出、只读审计记录。
8. 交付：自动化测试、部署配置、迁移和初始化命令、环境变量示例、运行文档；按开发文档补齐观测与多校部署配置。

阶段划分只控制施工顺序，不表示缩减最终范围。学生、家长按文档归为后续版本。

2026-09-22 用户确认额度规则：学校管理员直接给每位教师分配积分，不经过角色额度中间层。教师页面必须展示积分来源、历史总消耗及变更日志；学校总览汇总各账户余额与消耗。保留原子预占、结算、释放及幂等要求。

后续澄清：入库与数据库检索不天然产生模型接口费用，可使用学校本地向量模型，不默认接入付费服务。入库/检索不扣教师积分；若学校主动选择外部付费接口，实际费用由学校承担。教师仅承担回答生成积分，按回答模型实际输入（含资料上下文）和输出计量。

创作中心后续确认：PPT 等媒体生成也扣教师积分，采用预占、成功结算、失败/取消释放；目前没有指定媒体生成服务。上述“仅承担回答生成”是知识库问答场景的分工，不排除媒体创作消费。

## 接口与数据约定

沿用 /api/v1 与开发文档的核心路径。补充会话、知识库、Skill、任务创建和列表等页面实际需要的接口。普通响应遵守 code/message/data/requestId；列表采用 cursor 和 limit；SSE 使用文档指定事件，包含消息与调用标识，断线通过数据库消息恢复。

租户与用户身份只从已验证会话注入。教师只能访问本人私有资料以及授权的组织资源；管理权限由服务端验证，普通管理员不得删除审计。禁止把浏览器设置中的学校、角色作为权限依据。

## 外部条件处理

需要用户提供或指定真实模型、Embedding、OCR、多模态服务以及学校统一认证的接入方式。未配置的能力明确返回服务未配置错误，不能返回假生成结果或扣除额度。测试适配器仅用于自动化测试和明确标识的演示环境，不能作为真实能力验收证据。

首先实现账号密码登录；OIDC 和短信是否启用由学校接入条件决定。密钥不通过聊天明文索取、不写入代码或审计日志。

## 验收证据

- API 集成测试覆盖登录、停用与撤销、跨租户和跨用户越权、个人设置持久化、Skill 审核与版本约束。
- 数据库与队列集成测试覆盖重复提交、额度并发、失败退款、Worker 重启、取消与完成竞争。
- 浏览器端到端验证登录、教师生成与编辑导出、管理员资料上传与 Skill 发布、创作任务与错误提示。
- 真实服务配置后验证模型流式生成、文件解析检索引用及各类媒体产物；缺少凭据时这些项保持未验收。
- 上线前单独检查备份恢复、密钥、监控、告警与试点质量评测；不能以单元测试通过宣称生产上线完成。
