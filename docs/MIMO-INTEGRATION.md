# MiMo 真实接入验证

2026-09-23：用户提供 MiMo Token Plan 中国集群和 mimo-v2.5 模型。按官方文档 https://mimo.mi.com/docs/zh-CN/tokenplan/Token%20Plan/quick-access ，同一凭据可使用 OpenAI 兼容入口 https://token-plan-cn.xiaomimimo.com/v1 ，认证头为 api-key。未改用按量付费域名，也未切换用户指定模型。

部署配置保存在 deploy/backend.env；不在源码、报告或日志记录密钥。ProviderProfile 新增受限 auth_header（authorization / api-key），默认仍为 Bearer 认证，现有供应商行为保持兼容。

真实验证已通过直连流式解析，以及部署网站代理→FastAPI→MiMo→持久化回答→Token 积分结算→幂等重放不重复扣费。真实短请求使用 254 输入 Token、28 输出 Token；教学样例及网站链路实际用量见 MIMO-REAL-TEST.json。样例验证不代表全部教学质量、安全或知识检索已验收。

认证/模型运行回归 16 项通过，Ruff 通过。网站联调使用专用账号和每百万输入/输出各 1000 积分的临时测试配置，仅为验证结算，不是正式价格。测试后收回未使用额度、停用测试账号及模型，等待用户确定正式积分价格再启用默认模型。MiMo 凭据仍保留在本机部署环境中。

PPT、图片、音视频与向量模型并不因文本模型接入而自动可用。先前 SQLite 检索浏览器 OperationalError 仍需单独定位，不能被本次普通文字回答通过覆盖。

用户后续明确：模型配置与积分比例由学校管理员在后台维护，不要求用户在聊天中确定费率。已将联调模型改为“MiMo v2.5（待管理员配置）”，移除临时测试费率、保持停用且非默认。当前零值仅为未启用配置的占位，管理员应编辑费率、保存、启用并设为默认；明确配置为零则代表不扣积分。入口 /admin/models 已支持这些操作、版本冲突检查及费率版本审计。服务连接和密钥当前仍由部署配置提供，尚未提供管理员在线修改凭据的界面。
