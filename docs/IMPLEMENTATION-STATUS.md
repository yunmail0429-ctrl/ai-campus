# 实现状态（2026-09-22）

## 2026-09-23 知识库增量

已加入 CPU OCR（图片、扫描 PDF、Word/PPT 内嵌图片）、按页有序内容块与表格单元格保存、PPT 图表系列/类别提取、可配置视觉模型补充、Qdrant 稠密向量与中文 BM25 混合召回、可选重排和教师预览。Qdrant 是可重建镜像；数据库复核权限，未同步资料或 Qdrant 故障时回退 pgvector。旧资料可手动重新解析。真实 Qdrant 协议和本机 OCR 样本已验证；外部真实视觉/重排模型质量、8 GB 服务器下的完整服务容量和大批量文档回填尚未验收。

当前仍有边界：Word 的实际分页与图片/图表的精确视觉版式不能从现有结构块完全还原；解析版本历史、嵌入模型切换时的无中断双版本服务，以及视觉/重排供应商费用精确计量尚未实现。上线前应以真实教学资料核对复杂表格和图表，并在目标服务器测内存、磁盘和检索延迟。
