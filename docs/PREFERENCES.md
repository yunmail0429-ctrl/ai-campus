# 教师默认偏好

设置页的“使用偏好”保存默认 Skill、创作类型、PPT 页数（1–60）和创作风格。后端仍通过 `/me/preferences` 验证并按账号保存；只有本人私人 Skill 或同校已发布 Skill 可设为默认。个人偏好不会改变学校默认模型、权限或积分费率。

工作台和助手优先使用页面的临时选择；显式 Skill URL 和工作台传入选择优先于保存的默认值。选择“通用助手”也是有效的明确选择，不会被异步加载的偏好替换。可用 Skill 选择器读取全部分页，不将第一页之外的默认值误判为不可用。

默认 Skill 不再可访问时，新页面回退到通用助手；显式选中的 Skill 不可用时，提示重新选择并阻止提交，不偷偷换用另一个 Skill。服务端每次生成仍重新校验权限。

创作页使用默认类型、页数和风格；从明确类型的工具入口进入时保留该类型。临时修改只影响当前页面，不覆盖账号设置。提交结构包含 `options.style`，PPT 另含 `options.pages`。这是前端已接通的参数合同，资源任务后端与实际媒体产物仍在后续实施范围内。

验证入口：前端 `npm run build`、`npm run test:live -- tests/livezzz-preferences.spec.ts`。用实际账号/API 验证保存、跨页面应用、明确通用助手、不可用 Skill 恢复、慢响应不覆盖手动选择、PPT 参数提交和手机无横向溢出。创作测试只检查请求参数，不冒充生成成功。
