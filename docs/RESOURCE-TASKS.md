## 已实现接口

- `GET /api/v1/resource-tasks/capabilities`：六种类型的配置可用性。
- `GET/POST /api/v1/resource-tasks`：本人任务分页和提交；POST 要求 Idempotency-Key，正文为 kind、prompt、options，PPT 可附 pages，所有类型可附 style。
- `GET /api/v1/resource-tasks/{id}` 和 `/events`：本人状态与事件分页。
- `POST /api/v1/resource-tasks/{id}/cancel`：未启动的排队任务直接取消；在途任务记录取消请求，待执行器确认。重复取消不会重复释放。
- `POST /api/v1/resource-tasks/{id}/retry`：仅失败或取消任务可重试，要求新的 Idempotency-Key；创建关联的新任务，同键重试返回同一新任务，不覆盖原记录。
- `GET /api/v1/resource-tasks/{id}/download`：仅本人、成功任务和已就绪且未撤回的输出可取得 120 秒私有存储签名跳转；前端代理透传 Location。

任务创建与 Outbox 在同一事务提交，保存脱敏输入及不含凭据的适配器配置快照。请求正文不同却复用同键返回 409。学校管理员也不能读取其他教师的私人任务。列表不返回对象键、外部任务标识或内部快照。

## 教师任务记录

React 创作页使用游标加载更早任务，合并已加载页并按任务 ID 去重，保留先加载页的记录避免重叠旧页覆盖状态。已加载历史页中的排队/运行任务也参与 3 秒轮询。记录显示北京时间、类型、任务状态/进度和预占/实际消耗；失败/取消显示未扣积分及预占释放，学校承担策略单独显示。只有仍在运行/排队的取消请求显示正在取消，失败终态不会误示取消仍在进行。

提交、取消、重试，以及轮询发现任务进入终态时，刷新教师余额和积分流水缓存。页面沿用原有任务卡片视觉。前端 HTTP 夹具覆盖游标编码、加载历史、页边界去重、旧状态不覆盖、历史任务完成触发余额刷新与手机布局；实际 Next/FastAPI 偏好专项继续验证创作参数传递和未配置时拒绝创建。

## 计量配置边界

用户已确认 PPT 等媒体创作扣教师积分，`RESOURCE_PAYER` 默认 teacher。只有真实适配器配置完成才允许创建任务；没有服务时仍返回未配置错误且不扣分。代码也保留显式 school 策略供独立学校部署，不自动切换；测试覆盖两种策略。若部署主动设为 null，返回 `RESOURCE_BILLING_NOT_CONFIGURED`。

适配器 prepare 必须为无网络调用的本地校验/估算。教师策略在事务内按最大积分预占，成功文件就绪后按适配器提供的有效积分结算，超过预占金额拒绝结果并释放；失败/取消释放；学校策略不修改教师余额。固定报价或实际用量换算尚待用户选择，真实供应商计量由后续适配器实现。

## 公共执行器

`resource.step` 和 `resource.cleanup` 已注册到 Celery。一次执行只发起、轮询或取消一步，SQL 租约 3 分钟、进程硬超时 175 秒、适配器网络步骤 45 秒；外部调用在数据库事务外执行。外部任务 ID 持久化后恢复只轮询。没有 ID 的中断任务只有在适配器明确保证请求键去重时才允许再次 start，否则转入取消确认，避免盲目重复计费。

取消在途任务先保留预占，收到远端确认后释放；任务期限 2 小时，超过期限继续尝试取消，10 分钟宽限后以 `RESOURCE_CANCEL_UNCONFIRMED` 失败释放教师预占并留下事件/审计。此状态不代表供应商没有发生费用，需要后续供应商对账。

输出按类型检查 MIME/容器标识，PPTX 另检查 ZIP 大小、必要条目、CRC 和宏文件，随后必须经 ClamAV 扫描、私有存储写入，最终事务重新检查取消和租约，再原子结算与标记可下载。格式检查不等于内容质量验收。对象键和文件名由服务器生成；先写待处理输出记录，失败/取消异步清理，调度器恢复丢失的处理和清理投递。重复终态投递不重复扣费。
