# 知识库检索与引用实现计划

> 使用已应用的 writing-plans / executing-plans 在当前工作区内联实施。原项目授权持续有效；不另建审批步骤。

**目标：** 经过扫描的资料可以向量化、按权限检索，并作为带来源的对话上下文；刷新与重试保留来源和计费结果。

**用户确认与纠正：** 入库、数据库检索并不天然产生模型接口费用；可使用本地向量模型，不默认接入付费服务。入库/检索不扣教师积分；若学校选择外部付费服务，相关实际费用由学校承担。教师只为回答生成消耗积分。回答模型的输入包括实际发送给它的资料上下文；嵌入调用独立记录学校用量，不改动教师余额。

**架构：** 单校嵌入配置、每文档索引任务、可复用的分段向量、独立嵌入用量账本。PostgreSQL 使用 pgvector 精确余弦检索，SQLite 只作本地等价计算。查询先应用租户/个人/学校/对话权限，再排序取结果；删除或更换模型不得混用旧索引。
