# 学校使用统计实现计划

沿用已确认整体方案和持续开发授权，当前工作区内联执行，不重复申请批准。

设计：管理员查询本校北京时间闭区间日期（最多 366 天，默认近 30 天）；按调用发起时间统计调用状态、Skill 调用、确认 Token，按账本结算时间统计实际消耗。活跃明确为成功登录去重人数。SQL 聚合避免载入提示词和正文；每日序列补零。CSV 仅导出同口径聚合，带审计，不含个人标识与内容。资源产出未接入显示 null，不能伪装成零；货币成本仍待独立价格配置。

- [x] backend/app/statistics.py：日期校验、租户 SQL 聚合、每日统计、脱敏 CSV；main.py 注册。
- [x] React /admin/statistics：日期表单、汇总、每日明细、下载，沿用既有视觉。
- [x] 测试管理员权限、跨校隔离、日期边界、重复调用/失败不虚增消费、导出无个人内容；SQLite/PostgreSQL 与浏览器验证。
- [x] OpenAPI、实现状态与运行文档更新。完整项目范围不变。
