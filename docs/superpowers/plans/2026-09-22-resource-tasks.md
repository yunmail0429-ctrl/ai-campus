# 创作中心任务后端计划

完整范围：图片、PPT、音乐、视频、数字人、3D 的任务提交、进度、取消、重试、私有产物下载；事务 Outbox、幂等、恢复、计量和统计。与现有教师页面和保存偏好参数一致。

用户已确认目前没有指定生成服务，且 PPT 等媒体创作扣教师积分。采用教师预占、成功按有效计量结算、失败/取消释放规则；入库和检索仍不扣教师积分。不索取密钥，不自动配置付费供应商；公共任务基础独立实施。

分阶段实施，不以基础接口代替真实生成：

- [x] 数据与 API：resource_tasks/resource_outputs/task_events；本人权限；请求幂等、配置快照、受控状态、列表、详情、事件、取消/重试/下载。输出就绪由后续 Worker 实现，目前下载测试只使用明确播种的测试记录。
- [x] 公共 Worker：发起/轮询分离，外部任务 ID 持久化，租约和重复投递；取消与完成竞争、超时恢复、间隔重试、失败释放、私有输出及扫描，异步清理。数据库协议夹具覆盖，不代表真实供应商/队列链路验收。
- [ ] 供应商适配：依据用户指定接口实现真实能力；若未指定则先保留明确未配置状态，不能提供假产物。明确供应商去重/取消保证和未知费用窗口。
- [ ] 计量：根据确认的承担方接入学校用量或教师预占/结算/释放；价格采用配置快照。
- [ ] 前端：能力可用性、参数、请求重试复用键、进度、取消、重试、下载；产出统计。
- [ ] SQLite/PostgreSQL 幂等/权限/竞争/恢复，真实队列存储浏览器联调，供应商质量单独验收。
