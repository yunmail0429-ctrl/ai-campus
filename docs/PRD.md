# 西附两江智能教育助手：产品需求文档（PRD）

## 1. 文档信息

- 产品名称：西南大学附属中学两江中学智能教育助手
- 简称：西附两江智能教育助手
- 文档版本：V1.0
- 文档定位：首期 MVP 与后续平台化建设的统一需求基线
- 当前版本服务对象：教师、学校管理员\n- 后续版本服务对象：学生、家长

## 2. 产品定位

西附两江智能教育助手第一版是面向西附两江教师与学校管理员的 AI 教学工作平台。平台统一接入学校知识库、公共 Skill、学校模型与多模态 AI 能力，为教师提供教学生产力工具，为管理员提供统一的账号、内容、模型、积分和使用数据治理能力。学生学习伴读与家长家校共育属于后续版本。

平台建设遵循“学校统一建设、用户个性使用、经验持续沉淀、能力持续扩展”的原则，并支持后续复制到其他学校。

## 3. 建设目标

### 3.1 首期目标

第一版只重点设计并实现 6 个核心界面，形成教师使用与管理员治理的最小闭环：

1. 登录页：学校 Logo、学校名称、教师账号登录。
2. 教师 AI 工作台：AI 助手、命题审题、教案、PPT、绘图、数字人、视频、音乐、3D 入口。
3. AI 助手页面：左侧对话、中间工作区、右侧知识库与 Skill 调用状态。
4. Skill 中心：学校公共 Skill、我的 Skill、创建 Skill。
5. AI 创作中心：图片、PPT、视频、音乐、数字人、3D 模型。
6. 管理员后台：教师账号、知识库、Skill、模型、积分、使用数据。

本版优先验证教师工作流和学校管理闭环，学生端、家长端及复杂家校共育能力保留为后续版本。

### 3.2 非目标

- 首期不替代学校教务系统、成绩系统或心理诊断系统。
- 首期不直接输出高风险医疗、心理诊断或升学决策结论。
- 首期不绑定单一大模型供应商，模型通过适配层接入。

## 4. 用户与角色

| 角色 | 核心目标 | 主要权限 |
|---|---|---|
| 教师 | 提升备课、命题、批改和资源生产效率 | 使用公共 Skill、创建个人 Skill、管理个人工作空间与资源 |
| 学校管理员 | 管理平台运行和教育数据 | 管理账号、知识库、Skill、模型、额度、审计和报表 |
| 平台运维管理员 | 保障多校部署和系统稳定 | 租户、部署、监控、密钥和系统级配置 |

## 5. 产品信息架构

### 5.1 教师端

- 工作台：最近任务、常用 Skill、额度余额、资源快捷入口
- AI 对话：基于学校知识库和个人上下文的对话空间
- 教学 Skill：命题、审题、教案、作业批改、错题分析、课件生成
- 资源生产：文档、试题、PPT、图片、视频、音乐、数字人、3D 模型
- 个人知识库：上传教学资料、沉淀经验、设置可见范围
- 我的资源：草稿、已发布、历史版本、导出和分享
- 个人设置：账号、安全、偏好、额度与使用记录

### 5.2 管理端

- 组织与账号：学校、年级、班级、教师、学生、家长
- 知识库管理：资料上传、解析、分段、标签、权限和版本
- Skill 管理：审核、发布、下架、版本、适用角色和调用统计
- 模型管理：模型接入、路由策略、能力标签、成本和健康状态
- 额度管理：学校额度、角色额度、个人额度、消耗和预警
- 内容与安全：敏感词、输出审核、风险事件、审计日志
- 数据分析：活跃度、调用量、资源产出、节省时间和使用趋势
- 系统设置：品牌、通知、开放范围、数据保留和集成配置

## 6. 核心业务流程

### 6.1 教师生成教案

1. 教师选择“教案生成” Skill。
2. 选择学科、年级、课题、课时和教学目标。
3. Skill 检索学校知识库与教师个人资料。
4. 模型生成教案初稿，并展示引用来源。
5. 教师编辑、保存版本、导出 Word/PDF 或发布到个人资源库。
6. 教师可将修改后的结果沉淀为个人模板或 Skill 示例。

### 6.2 管理员发布公共 Skill

1. 管理员创建或导入 Skill。
2. 配置适用角色、知识库范围、模型策略和额度规则。
3. 通过测试样例进行质量与安全校验。
4. 提交审核并发布到指定年级、学科或全校。
5. 持续查看调用量、成功率、反馈和版本效果。

## 7. 功能需求

### 7.1 账号与权限

- 支持手机号、学校统一身份认证或管理员批量导入。
- 支持 RBAC，并支持班级、学科、年级等数据范围控制。
- 支持家长与学生绑定关系管理。
- 支持登录设备管理、异常登录提醒和账号停用。

### 7.2 知识库

- 支持 PDF、Word、PPT、图片、网页和纯文本。
- 支持 OCR、结构化解析、切片、向量化、标签和版本管理。
- 支持学校级、学科级、年级级、个人级可见范围。
- 回答结果展示引用来源和更新时间。
- 支持知识库质量抽检、失效资料下线和增量更新。

### 7.3 Skill

- Skill 包含名称、说明、适用角色、输入字段、提示模板、工具权限和输出格式。
- 支持公共 Skill、组织 Skill、个人 Skill 三层作用域。
- 支持草稿、测试、审核、发布、下架和版本回滚。
- 支持调用反馈、评分、成功率和成本统计。

### 7.4 多模态资源生产

- 文本：教案、试题、解析、通知、学习计划。
- 文档：Word、PDF、Markdown。
- 演示：PPT 大纲与可编辑 PPT。
- 图像：教学插图、实验示意图、知识卡片。
- 音视频：讲解音频、课程视频、数字人脚本和成片任务。
- 3D：教学模型描述、生成任务、预览和下载。
- 长任务进入任务中心，支持进度、失败原因、重试和结果留存。

### 7.5 数据与分析

- 统计账号活跃、Skill 调用、模型调用、资源产出和额度消耗。
- 支持按时间、组织、角色、学科、年级筛选。
- 管理员可导出脱敏报表。
- 所有高风险操作写入审计日志。

## 8. 安全与合规要求

- 最小权限、默认私有、明确授权、可撤回。
- 学生和家长数据分级分类，敏感字段加密存储。
- 模型调用前进行数据脱敏和提示注入防护。
- 输出增加事实性、引用、风险和适用范围提示。
- 对心理、生涯、健康等内容设置安全策略和人工转介机制。
- 支持数据保留期限、删除申请、导出和审计追踪。

## 9. MVP 验收标准

1. 教师可从登录页进入工作台。
2. 工作台清晰呈现 8 类 AI 能力入口，并可进入对应创作流程。
3. AI 助手页面可完成对话、知识库检索、Skill 调用、结果编辑和导出。
4. Skill 中心可区分学校公共 Skill 和个人 Skill，并可创建个人 Skill。
5. AI 创作中心可统一发起图片、PPT、视频、音乐、数字人和 3D 任务。
6. 管理员后台可完成教师账号、知识库、Skill、模型、积分和使用数据管理。
7. 核心页面具备加载、空态、失败、无权限和任务进行中状态。

## 10. 后续版本方向

- 多学校多租户复制部署。
- 学校 Skill 市场和教师经验共享机制。
- 与教务、作业、成绩、校园统一身份系统对接。
- 更丰富的智能批改、学情预测和教学研究分析。
- 模型评测中心、自动回归测试和成本优化。
