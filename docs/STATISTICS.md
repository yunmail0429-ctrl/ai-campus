# 学校使用统计

管理员入口 `/admin/statistics`，接口 `GET /api/v1/admin/statistics`；`/export` 下载 UTF-8 BOM CSV。两者接受 `start=YYYY-MM-DD&end=YYYY-MM-DD`，日期含首尾，使用北京时间，默认近 30 天，最多 366 天。教师无权查询或下载，所有查询均限定当前学校。

## 口径

- 登录活跃账号：区间内成功登录的去重账号数，包含管理员；持续保持登录但没有再次登录的账号不会计入此指标。每日人数按天去重，不能将每日人数相加当作区间活跃人数。
- 模型调用：持久化教学调用记录，按发起日归属，显示完成/失败/取消/进行中。相同请求键重放不会新增调用。模型连接检查不计入教学调用。
- Skill 调用：教学调用快照中包含 Skill 的子集，与模型调用有重叠，不能将两者相加。当前为总量，尚未提供按 Skill 分组的成功率/评分报表。
- 成功率：完成数除以完成、失败和取消之和，进行中不进入分母；无结束调用显示无数据。
- 确认 Token：仅已完成教学调用的有效输入/输出计量，按请求发起日归属。不是供应商账单；失败调用可能存在未确认的外部费用。
- 实际消耗积分：积分账本 `settle` 的余额减少量，按结算日归属。预占、释放、管理员分配或收回不计入。跨午夜生成时，调用与消费可能出现在不同日期。
- 学校知识库用量：嵌入调用（包含索引、查询、检查）、完成调用确认的输入 Token、未确认计量次数。教师不为入库/检索扣积分。
- 资源产出：按创作任务首次成功事件的北京时间日期统计。成功事件与文件就绪、积分结算在同一事务提交；对同一任务去重后再筛选日期，不把创建、进行中、失败、取消算作产出。按图片/PPT/视频/音乐/数字人/3D 分组，保留历史成功数量，不因后续文件清理改变完成日。只代表本系统记录，不表示供应商已配置或校外没有产出。媒体任务不计入文字模型调用次数；其教师积分结算计入实际消耗积分。
- 回答评价数量及均分：只汇总当前有效的 1–5 分评价，按最近提交日期归属；修改后移至最近日期，撤回从当前报表剔除。是自愿反馈样本，不等同于全体教师满意度或客观教学质量。CSV 增加每日评价数量与评分合计，不含说明原文。

教师可在已完成回答下保存、修改或撤回评价，仅对话所有者可操作。反馈说明最多 1000 字，保存前做已有手机号/邮箱/身份证脱敏，只有本人消息接口返回；不进入管理员汇总、导出或审计原文。评价不调用模型、不修改积分。删除对话后不能继续操作评价，已有匿名聚合仍保留；历史报表不是不可变快照。

每日明细补零，汇总从同一每日调用/消费/产出结果计算。查询实时读取数据库，正在执行的调用可能在下次查询时更新状态；不提供冻结历史报表快照。当前无供应商货币成本或按教师排名统计。接口 resourceOutputs 为六类产出数量对象，summary.resourceOutputs 与每日 resourceOutputs 为总数；CSV 追加总产出和六类产出列。

## 脱敏导出

CSV 只包含日期和聚合数值，不包含姓名、账号、手机号、个人标识、提示词、回答、Skill 名称或文件原文。日期与数值由服务端产生，不接受用户文本作为单元格。导出记入 `statistics.exported` 审计，记录查询范围和操作者，不记录文件内容。

## 验证入口

```powershell
cd backend
$env:PYTEST_DEBUG_TEMPROOT=(Resolve-Path local-data).Path
.venv\Scripts\python -m pytest tests/test_statistics.py -q
.venv\Scripts\python tests/run_postgres.py
cd ../frontend
npm run build
npm run test:live
```

专项覆盖权限、跨校隔离、北京时间边界、跨日结算、登录去重、重复请求不重复计数、失败不虚增用量、CSV 无个人内容与导出审计。浏览器验证实际 Next/FastAPI 链路的日期筛选、下载和手机布局。教学生成数据来自本机协议夹具，不作为真实模型质量证据。
