# AI Campus

基础教育人工智能平台项目源码。仓库包含前端、后端、部署配置、测试和项目文档。

## 目录

- `frontend/`：Next.js 前端应用，使用说明见 `frontend/README.md`。
- `backend/`：Python 后端服务，使用说明见 `backend/README.md`。
- `deploy/`：部署与联调脚本，使用说明见 `deploy/README.md`。
- `docs/`：需求、设计和开发说明。
- `assets/`：项目所需的静态素材。

启动前请按各目录中的 `.env.example` 配置本地环境。实际凭据、数据库、运行数据、测试产物和商业报价文件不纳入仓库。
